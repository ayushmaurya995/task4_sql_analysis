# SQL Data Analysis Project

## Overview
A SQL analysis project demonstrating data extraction, transformation, aggregation, joins, filtering, and analytical queries.

## What This Project Demonstrates
- SELECT, WHERE, ORDER BY, GROUP BY, HAVING
- INNER / LEFT JOIN patterns
- Subqueries and analytical logic
- Aggregations and KPI-style calculations
- Translating business questions into SQL queries

## Tech Stack
- SQL
- Relational database concepts

## How to Run
1. Clone this repository.
2. Open the SQL files in your preferred database client.
3. Create/import the required tables and data.
4. Execute the queries and review the results.

## Skills Demonstrated
SQL querying, data analysis, relational data modeling concepts, and analytical problem solving.
